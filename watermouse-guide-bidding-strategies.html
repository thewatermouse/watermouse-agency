Manual vs automated bidding: which should you use?

By Rodrigo Kato7 min readUpdated September 2026
The short answer

For most eCommerce in 2026, automated (Smart Bidding) wins: it adjusts bids per auction using signals no human can act on fast enough. Manual CPC is now a niche tool. The real choice is which automated strategy: use Maximise conversion value + a target ROAS once you have enough conversions and clean revenue values, and Maximise conversions (or no target) while data is still thin. The catch: Smart Bidding is only as good as the conversion data you feed it.

“Should I bid manually or let Google do it?” used to be a real debate. In 2026 it mostly is not, because Smart Bidding sees things you cannot: the user's device, time, location, browser, query context and much more, and prices each auction accordingly, in real time. But automated is not one thing, and picking the wrong strategy (or the right one too early) can still hurt. Here is how to choose.

Manual vs automated, in one paragraph

Manual CPC means you set the maximum you will pay per click and adjust it yourself. It gives total control and zero intelligence, you cannot react to the hundreds of signals that decide whether a given click is worth 20 cents or two euros. Automated (Smart Bidding) hands that per-auction decision to Google, which optimises toward a goal you set (conversions, or conversion value). For a store with real conversion data, that trade, giving up manual control for machine speed and signal, is almost always worth it.

The Smart Bidding menu

StrategyOptimises forBest for
Maximise conversionsThe most conversions for the budgetEarly on, or when every order is worth roughly the same.
Maximise conversions + target CPAConversions at a set cost eachLead-gen, or stores wanting a fixed cost per sale.
Maximise conversion valueThe most total revenueMost eCommerce, where order values vary.
Maximise conversion value + target ROASRevenue at a set return (e.g. 4x)eCommerce with enough data and clean revenue values.

For a typical online store, the destination is usually Maximise conversion value with a target ROAS, because it optimises for money, not just order count. The question is when to get there.

Which to use, and when

Match the strategy to how much data you have and what you are optimising for:

  • New campaign, thin data: start on Maximise conversions or Maximise conversion value with no target. Let it gather conversions and learn before you constrain it.
  • Enough conversions, values flowing: switch to Maximise conversion value and introduce a target ROAS, set just above your break-even ROAS.
  • Orders all similar in value: a target CPA can be simpler and just as good.
  • Tiny or very unusual account: the rare case where manual control still earns its keep, but for most stores this is not you.

The prerequisite that makes or breaks it

Smart Bidding predicts the value of each auction from your conversion data. If that data is wrong, the bidding optimises confidently toward the wrong thing, and you will not easily see it happening.

Before trusting any automated strategy, make sure: your conversion is the purchase (not add-to-cart), it carries real revenue values so a target ROAS means something, and your tracking and consent are set up so conversions are actually recorded (the same foundation behind why Google Ads and GA4 never quite match). Smart Bidding on broken data is worse than manual.

The mistakes that undo good bidding

  • Target set too aggressively. Too high a ROAS (or too low a CPA) target starves the campaign, it stops bidding on all but the safest conversions and volume collapses.
  • Changing the target too often. Big or frequent target changes reset the learning period. Adjust in small steps and give it time to settle.
  • Too few conversions per campaign. Fragmenting the account leaves each campaign without enough data to bid well, a core reason to consolidate rather than fragment.

Frequently asked

Should I use manual or automated bidding in Google Ads?

For most eCommerce accounts in 2026, automated (Smart Bidding) wins, because it adjusts bids per auction using signals a human cannot see or act on fast enough. Manual CPC is now rare, reserved for very small or unusual cases where you want total control. The real question is not manual versus automated, but which automated strategy to use and whether your conversion data is clean enough for it to work.

What is target ROAS (tROAS)?

Target ROAS is a Smart Bidding strategy where you tell Google the return on ad spend you want (for example 4x) and it bids to hit that on average, spending more on auctions likely to produce high-value sales and less on the rest. It works best once a campaign has enough conversions to learn from and is sending accurate revenue values, otherwise the target is guesswork.

What is the difference between Maximise conversions and Maximise conversion value?

Maximise conversions optimises for the number of conversions, treating each as equal, which suits lead generation or stores where orders are similar in value. Maximise conversion value optimises for total revenue, favouring higher-value sales, which suits most eCommerce where order values vary. You can layer a target on either: a target CPA on Maximise conversions, or a target ROAS on Maximise conversion value.

When should I add a target ROAS to a campaign?

Once the campaign is getting a steady flow of conversions and sending accurate revenue values, add a target ROAS set a little above your break-even ROAS. Starting a brand-new campaign straight on an aggressive target often starves it, so many operators begin on Maximise conversion value with no target (or a soft one), let it gather data, then introduce and tighten the target gradually.

Does Smart Bidding need a lot of conversions?

It needs enough to learn from a steady flow, not a fixed magic number. Smart Bidding predicts the value of each auction from your conversion history, so a campaign with only a handful of conversions a week will be volatile and slow to settle. That is a core reason to consolidate rather than fragment your account, so each campaign has enough data for the bidding to work.
